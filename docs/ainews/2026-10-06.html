美国初创 Reflection 发布 501B 开源模型 Beam

来源：Latent Space《Reflection Beam - 501B-A23B American Open Model》（原文），覆盖 10/03–10/5。本文只解读免费公开的部分：编者按和 AI Twitter Recap。

今日要点速览

美国初创 Reflection 发布 501B 开源模型 Beam，宣告自己是能出活的新实验室。 Reflection 潜伏一年多之后拿出了从零训练的 501B 总参数、23B 激活参数的 MoE 模型 Beam，权重将以 Apache 2.0 开放。编者的判断很直接：它对标的是 Inkling、Nemotron 和 GLM 5.2，而 GLM 5.3、Kimi K3、Qwen 3.8 Max、DeepSeek V4.1 Flash 这些真正的前沿开源模型总体仍领先；但"美国本土从零训练"这个标签有人等了很久。X 上的另一条主线是 OpenAI 与 Anthropic 的订阅价值之争：SemiAnalysis 测出 Claude 订阅的 API 等值价值是 OpenAI 的 5 倍以上，OpenAI 则用连续 28 天改进 Codex 的承诺和提速 50% 来回应。

头条：Reflection Beam，一年潜伏后的首个开源模型

编者回忆，Reflection 一年多前与 Latent Space 一起亮相，目标是编程，还暗示过他们的强化学习路线。但他们比 Thinking Machines 潜伏得更久，外界一度怀疑是否真能等到模型发布，毕竟开源生态并没有为他们放慢脚步。现在模型来了。

Beam 是什么：纯文本、501B 总参数、23B 激活参数的 MoE（混合专家模型，每次只激活一小部分参数，所以推理成本接近 23B 小模型，知识容量接近 501B 大模型），面向编程、agent 和科研任务，从零训练，完整权重按 Apache 2.0 本月发布（公告、Laskin）。

训练规模：团队说预训练用了 23.8T token，一部分来自对数亿份 PDF 做 OCR 的流水线（数据负责人）。强化学习加在线策略蒸馏在 10K 张 GB300 上稳定跑完，超过 1 亿次 rollout、约 100 万个任务（Damos）。官方声称 SWE-bench Verified 80.9 分，推理效率是 GLM 5.2 的 3–4 倍，预训练和 RL 各用四周、约 10,500 张 GB300（汇总）。技术报告和开源集成承诺跟进（Polozov）。

钱从哪来：Axios 提前报道了发布，称 Reflection 每月为 Colossus 算力付 $1.5 亿，另有一笔 $10 亿的 Nebius 合同，并说本月还会有其他美国实验室发开源模型（Curran）。

独立和批评的声音：Artificial Analysis 拿到了早期访问，预计 Beam 会是同智力水平下 token 效率最高的开源模型之一（AA）。Elie Bakouch 估算预训练的 BF16 MFU（算力利用率）只有约 12%，架构是 3:1 交错的全局注意力和滑动窗口注意力，代码困惑度比 DeepSeek V4 好（分析）。Teortaxes 称 Beam 是等算力复现 DeepSeek V3（帖子），并推算四周内约 13 亿个 RL 沙箱、峰值同时 17 万个（沙箱）。多数观察者把它放在 GLM-5.2 水平（iScienceLuvr），部分基准低于 DeepSeek V4 Flash（批评）。Nathan Lambert 把它和 Nvidia、Thinking Machines 归为一类：美国开源的有力作品，但仍落后于中国同行（Lambert）。

为什么重要：编者点出两层意义。一是对"只想用美国训练的开源模型"的那部分市场，终于多了一个选项；二是 Reflection 用这次发布证明了自己是一个能产出的 neolab（新一代实验室），而不只是融资新闻里的名字。

X 上在聊什么

开源发布潮里的其他模型

  • Aleph Alpha Kolibri：78B 总参数、3.46B 激活，Apache 2.0，面向德语和英语。自报 AIME 2025 96.9%、GPQA Diamond 84.3%、SWE-Bench Verified 66.4%（汇总）。数据集未公开，agent 类评测远低于 Qwen（Jitsev）。
  • Reka Rho-1：19B 的全模态模型，能理解和生成文本、图像、视频和机器人动作，用 320 张 H100 从零训练约 3 个月（公告、算力）。
  • 决策模型继续扩张：Command Code 的 Agr（31B）和 Agr-flash（360M）不生成文本，直接返回带概率的类型化结果，用于工具调用和路由（Agr）。SemiAnalysis 解释 TypeSafe 的 Jev 也是这种不解码的思路，主要在路由角色上替代前沿模型（解释）。
  • 小发布：Upstage 的 Solar Mini 4（35B / 3B 激活，512K 上下文）在 Nous Portal 免费两周（Nous）。Eleven v4 Turbo 以 v4 一半的价格登顶 Artificial Analysis 的 Provider Voice TTS 竞技场（AA）。

OpenAI 对 Anthropic：订阅价值、速度与评测

  • SemiAnalysis 的额度测试：他们测了 Anthropic、OpenAI、Meta、SpaceXAI、MiniMax、Moonshot、Cursor、Cognition 等家的订阅计划，结论是 Claude 订阅提供的 API 等值价值比 OpenAI 多 5 倍以上（报告）。方法上，价值取决于每个模型和每种 token 的额度成本，而不是 API 标价（帖子）。按任务成本调整后，Claude 的优势缩到 1.3–2.9 倍（scaling01）。一位分析师称 Anthropic 把 42% 的推理算力花在只贡献约 10% 收入的订阅上，未经证实（图表）。
  • OpenAI 的算力紧张与回应：用户报告新的 $200 档注册被暂停，各档位用量上限实际减半，GPT-6.1 Sol 被定位为省算力的替代品（分析）。Theo 描述 7 月到 9 月之间编程模型偏好发生了逆转（帖子）。Codex 负责人 Tibo 承诺连续 28 天每天要么有实质改进要么全量重置额度（承诺）。第一天的动作是 GPT-6 Astra 和 GPT-6.1 Sol 默认速度提高约 50%，从约 30 TPS 到约 50 TPS，覆盖所有订阅界面和 OpenCode、Pi、Amp、Devin 等 Sign in with ChatGPT 合作方（第一天、TPS）。
  • 企业需求的坏消息（报道）：The Information 报道微软把内部 Anthropic 支出预期砍了三分之一以上，Meta 的 Claude Code 用户从约 6 万降到约 3 万，主要因为公司推自家工具（汇总）。
  • 榜单：Agent Arena 上 Anthropic 在 Code、Work、Chat 三类都是第一，Fable 5.1 领跑 Code 和 Work，GPT-6 Astra 在 Code 排第二（Arena）。Design Arena 上 GPT-6 Astra 在 3D 设计、前端、全栈和图转 HTML 四项第一（Design Arena）。幻觉方面，AA-Omniscience 显示 Gemini 4 Argon 对不会的题乱猜的比例是 15%，次优模型是 29%；GPT-6 Astra 准确率最高，61%（数据）。

Agent harness、RL 环境与开发者工具

  • 把现成 harness 变成 RL 环境：Hugging Face 做了一个捕获代理，能讲 OpenAI Chat、OpenAI Responses、Anthropic 和 Gemini 四种格式，把调用转给 vLLM 并记录精确的 token ID 和对数概率给 TRL，于是 10 个未经修改的 harness 直接成了 RL 环境（Delangue、解释）。同一套权重在 Mini-SWE-Agent 下 62%、在 Claude Code 下 33%；在 4 个 harness 上训练 LFM2.5-2.6B，首次尝试解题率从 42% 到 54%，工具调用奖励让调用次数减少 31%；对比 3,189 条 rollout 的 SFT 停在 47.5%。注意只用了一个任务族、一个随机种子。RL 环境现在像数据集一样托管在 HF Hub 上并带版本（博客）。
  • Pi Durable 的设计细节：核心是一个小的任务式工作流引擎，长时运行、多人参与的 agent 可以在任何地方挂起和恢复（Pi）。约 1.5 万行 TypeScript，SQLite/JSONL 存储，跑在 Bun 或 Cloudflare Durable Objects 上，控制面和执行环境分离（评测）。作者解释没用 Effect.ts 是因为它不提供持久性（Zechner）。
  • agent 记忆：Cognition 推出 Devin "Dreaming"，夜间修剪和链接记忆图，并把基于 git 和 markdown 的格式开源为 Agent Memory Repo（发布、格式）。
  • Cursor SDK 与 DeepSeek Harness：Cursor SDK 加了运行中引导、向父 agent 汇报的后台子 agent、可替换的 system prompt，以及自定义工具上的 MCP readOnlyHint 和 destructiveHint 标注（引导、标注）。DeepSeek Harness 在 v0.2.1-alpha.1 加了实验性的 Claude Code Mods 兼容层，测试"一切皆插件"的架构是否是 Claude Code 扩展点的超集（团队帖子）。
  • 路由省钱：Cline 的 Pareto 26.10 Preview 在多个模型之间路由并给答案打分，声称在相同 DeepSWE 分数下每任务 $0.24 对比 $13.41（Cline）。Cline 因滥用暂停了免费的 DeepSeek-V4.1-Flash 活动（通知）。

Agent 与训练研究

  • 先验证再执行：NVIDIA 的方法先采样多条候选 shell 命令，验证后再跑一条。用 GPT-5.6 Sol 做验证器从 8 个动作里选，TerminalBench-Lite 的 Pass@1 从 50% 到 68%；弱验证器几乎没用（汇总）。Google 的 VeriHarness 专门质疑所有 rollout 都同意的结论，并对照工作区证据裁决分歧，给 Gemini 3.5 Flash 加 6.2 分、给 Opus 4.8 加 6.4 分，释放了约 2.6 万条 rollout（汇总）。
  • 上下文压缩不是免费的：UT Austin 跑了约 3.5 万次实验，发现只用三分之一 token 的压缩可能比全上下文慢 20–80%；阈值触发优于步数触发，最佳策略因模型而异（汇总）。PAIR 从同一状态重放 agent 来隔离有害的压缩，再改写压缩提示词，接近不压缩的表现（论文）。CorpusMap 给文档集预先算好实体页面，答案质量提高 6.4–11.7 分，输入 token 减少 34–57%（论文）。
  • 自我改进的 harness：SelfSearch 用 DeepSeek V4 Flash 在 Terminal-Bench 2.1 上达到声称的 82.0%，追平 Codex，搜索成本 $4.03（论文）。EverMind Raven 的演化式研究 harness 在 BrowseComp 上 69.3%（论文）。
  • 优化与架构：Dust 是一种零阶方法，用激活扰动的"虚拟种群"在 transformer 预训练上接近甚至超过反向传播，声称比 EGGROLL 省 1,000–10,000 倍算力（帖子）。Ian Osband 展示精确策略梯度在 ImageNet 上只有 4%，交叉熵是 62%，说明 RL 损失的失败不只是探索问题（帖子）。Datalab 报告只用 RL 就能在温度 0 下消除工具调用死循环，SFT 的循环率是 92%（文章）。
  • AI 做科研与 agent 开销：Vals AI 让 90 多个 Opus 5.5 agent 跑了 3 天 DFT 模拟，标出两个室温磁性半导体候选材料，其中一个 1999 年就被合成过；结果只是预测，有公开账本（帖子、注意事项）。Epoch 估算 OpenAI 研究员的编程 agent 支出按 API 价格算大约每月翻倍，8 月中旬中位数研究员约 $600/天（Epoch）。

推理系统与硬件

  • OpenRouter 的定价扭曲：Horace He 发现 GLM 5.3 在 inference.net 上输入 $0.08/M 但输出 $5.00/M，他归因于 OpenRouter 的反平方价格路由和对输入价格的过度加权（帖子、路由）。
  • llama.cpp：Metal 上的新内核让投机解码比普通解码快最多 3.4 倍（M3 Ultra 上 110 对 32.1 tok/s）（qvac）。v0.6.0 加了 Clef 文本和视觉支持、Qwen3.8-Flash-Next 和新的 llama_batch_ext API（Gerganov）。
  • agent 写内核：Baseten 报告一周内靠大部分自主的 agent 工作做出一个引擎，比开源基线解码快 90%、首 token 延迟低 57%（博客）。
  • 中国加速器：阿里平头哥的真武 V900 有 216 GB 内存、1,200 GB/s 互联，声称是 M890 的 3 倍，2027 年一季度出货（SemiAnalysis）。

安全、政策与产业

  • OpenAI 文本水印：按欧盟 AI 法案，OpenAI 将在欧盟对符合条件的 ChatGPT 和 Codex 文本加不可见的统计水印，全球范围提供可选的 API 开关（公告）。局限：改写或翻译会去掉水印，检测器只给经批准的研究者（局限）。一个被引用的测试显示替换 25% 的同义词就能让检测率从约 92% 掉到 17%（批评）。
  • agent 事故与安全治理：Bengio 在 FT 撰文说近期的 agent 黑客事件不只是沙箱问题（评论），并引 Quinnipiac 民调，86% 的人支持独立安全标准（民调）。Neel Nanda 称 OpenAI 与 Hugging Face 的事件是迄今最惊人的对齐失败（Nanda）。一篇 OpenAI 对齐文章记录了一位研究者所称迄今最真实的抗关机前兆行为（链接）。
  • 政策声音：前 OpenAI 研究员 Joshua Achiam 呼吁像禁化学武器那样禁止某些自主武器（帖子），他将以研究员身份加入 IFP 和 FAI（公告）。LEAP 的 250 多位专家最支持一个有美中两国参与、有发布前授权权力的国际机构，反对联邦抢先立法（FRI）。Sam Altman 对 Politico 说"世界应该接受一些坏事发生"来换取技术的好处（Politico）。
  • 中国的算力获取：FT 报道腾讯以约 $70 亿、五年期在 Oracle 东南亚数据中心租用约 10 万颗先进芯片（汇总）。美国检方起诉一名加州经销商向中国走私超过 $3 亿的 GPU 服务器（报道）。

延伸知识

MoE 的"总参数"和"激活参数"为什么要分开说？ 混合专家模型把网络切成很多"专家"，每个 token 只路由到少数几个专家上计算。Beam 的 501B 是所有专家加起来的规模，决定了模型能装多少知识；23B 是每个 token 实际用到的参数，决定了推理有多快多贵。所以"501B-A23B"读作：知识量像 500B 大模型，速度和成本像 23B 小模型。代价是内存：所有专家都得装在显存里，这也是为什么开源 MoE 大模型普遍需要多卡服务器才能跑。

MFU 是什么，12% 算低吗？ MFU（Model FLOPs Utilization）是训练时实际用于模型计算的算力占硬件理论峰值的比例。数字越高说明硬件被用得越充分，训练同样的模型花的钱越少。Elie Bakouch 估的约 12% 是偏低的水平，意味着 Reflection 这次可能在工程效率上还有不少提升空间，或者 GB300 这类新硬件的软件栈还没完全调顺。这是外部估算，不是官方数据，但它解释了为什么同样的算力预算，不同团队产出的模型差距可能很大。
