今日要点速览

Anthropic 发布 Claude Haiku 5.5，价格对齐 GPT-6 Luna，分数更高。 这是 Haiku 系列约一年来的第一次更新。官方说法是"我们发过的最便宜、最快、最强的小模型"，平均运行成本比 Haiku 4.5 低约 75%。Artificial Analysis 的独立评测给它 43 分，略高于 GLM-5.3 Flash、Gemini 3.8 Flash 和 GPT-6 Luna，但它用的 token 大约是 Luna 的 3 倍，这是最大的注意事项。同一天 Anthropic 还把 Sonnet 5.5 的缓存读取价格砍半，并给 Max 和 Team 订阅附赠每月 API 额度，被解读为一轮针对 agent 经济的协同出击。

头条：Claude Haiku 5.5，便宜一档的"小而强"

编者按的背景：Anthropic 发布 Haiku 4.5 已经约一年，之后 Sonnet、Opus 和 Fable 一路更新到 5.5，Haiku 这条线有点被遗忘，尤其是 OpenAI 已经把 Luna 6 和 Astra、Sol 6 一起推了出来。现在 Haiku 5.5 到了，编者评价是"受欢迎的更新"。

发生了什么。Anthropic 发布 Claude Haiku 5.5，定价对齐 OpenAI 的 GPT-6 Luna，同日下调 Sonnet 5.5 和订阅计划的价格。

  • 发布前的信号：@scaling01 在公告前发了"happy Haiku 5.5 day"；@kimmonismus 说模型已经出现在 Claude Code 的更新里，预测会是"Luna 定价"，随后抢先贴出了价格并确认上线。
  • 官方发布：@claudeai 和 @AnthropicAI 称它是"我们发过的最便宜、最快、最强的小模型"，平均运行成本比 Haiku 4.5 低约 75%。
  • 定位：已在 Claude Platform 和 Claude Code 上线（@ClaudeDevs）。Anthropic 把它定位成与 Opus 5.5 或 Sonnet 5.5 搭配的子 agent，负责摘要、压缩上下文、查数据库这类大批量、对成本敏感的活。@mikeyk 的概括是"Opus 负责重思考，Haiku 负责大批量"。
  • 分级定价（@ClaudeDevs）：提示词在 100K token 以下，每百万 token 输入 $0.10、输出 $0.50，缓存读取 $0.01；超过 100K，输入 $0.50、输出 $2.50，缓存读取 $0.05。也就是长上下文价格是短上下文的 5 倍。
  • Sonnet 5.5 降价：缓存读取从每百万 $0.20 砍到 $0.10，Anthropic 说这让 Sonnet 5.5 在大多数长时间运行或 agent 类工作上便宜约 20%（@claudeai）。
  • 订阅送 API 额度：Max 5x 每月送 $100、Max 20x 送 $200、Team 最多 $500（团队共享），任何模型包括 Haiku 5.5 都能用，第三方 harness 里也能用（@ClaudeDevs）。
  • SDK 同日更新：电脑操作和浏览器操作工具集内置到 Python 和 TypeScript 的 Claude SDK 里。SDK 自己跑动作循环，把点击和按键发给 browser_use、Browserbase、E2B 或 Daytona 的驱动，开发者不用再自己写这个循环（@ClaudeDevs、快速上手）。
  • 首日合作方：Cursor 称短请求上成本是"Haiku 4.5 的十分之一"，并发布了 CursorBench 对比（@cursor_ai、对比）。VS Code 的 GitHub Copilot 报告它"在许多编程任务上追平 Claude Sonnet 5，用更少的 token 和步骤"（@code）。Devin 报告 FrontierCode 1.1 上 58.4%，领先 Sonnet 5，每任务成本约为八分之一，并推荐在 Fusion 里让它做 Opus 5.5 主导下的"副手"（@cognition）。Arena 已加入 Agent Arena、Code Arena WebDev、Text、Document 和 Vision，分数待出（@arena）。

为什么重要：编者和多位评论者的共同读法是，这不是一次孤立的小模型发布，而是 Anthropic 在"agent 经济"上的一次协同动作：便宜的工人模型、更便宜的缓存、订阅附赠 API 额度，三件事同一天落地，目标是让多模型 agent 架构（大模型指挥、小模型干活）在成本上跑得通。对普通用户的直接影响是，订阅 Max 的人从此每月多了一笔可以在任何 harness 里花的 API 额度；对开发者的影响是，低价端第一次出现了一个在 agent 类评测上明显领先同价位对手的选项。

X 上在聊什么

Artificial Analysis 的独立评测

  • Intelligence Index 43 分：@ArtificialAnlys 给出了最详细的第三方数据（分项、对比页）。最高推理强度下 43 分，比上一代 Haiku 高 26 分；略高于 GLM-5.3 Flash（42）、Gemini 3.8 Flash（41）和 GPT-6 Luna（38）；与 Kimi K3（44，一个 2.8T 参数的开源权重模型）相当；比最高强度的 Claude Sonnet 5.5（56）低 13 分。这是第一个带 Anthropic 推理强度设置和自适应思考的 Haiku。一个小模型能和 2.8T 参数的 Kimi K3 打平，说明后训练和推理时间的投入已经能在很大程度上弥补参数规模的差距；但和 Sonnet 5.5 的 13 分差距也提醒，小模型的上限仍然明确。
  • token 用量是主要注意事项：最高强度下每个 Index 任务约 162k 输出 token，大约是 GPT-6 Luna 最高强度（约 50k）的 3 倍。从 xhigh 到 max 多得 2 分，但 token 多 1.8 倍。同分对比也更啰嗦：Haiku 5.5 在 high 强度下 38 分用约 55k token，Luna 在 max 下 38 分用约 50k，强度越低差距越大。成本数字是临时的，因为 Artificial Analysis 还没把 100K 以上 5 倍的价格阶梯建进模型。
  • 分项：AA-Briefcase（私有的 agent 知识工作评测）1578 Elo，领先 Kimi K3 和 GLM-5.3，与 Muse Spark 1.3 最高强度相当。Terminal-Bench 4.0 得 33%，Haiku 4.5 是 0%；与 GLM-5.3 Flash 持平，领先 Gemini 3.8 Flash（20%）和 GPT-6 Luna（13%）。
  • 知识与幻觉（AA-Omniscience）：Haiku 5.5 准确率 36%、幻觉率 40%；Gemini 3.8 Flash 55%、55%；GPT-6 Luna 44%、77%。Haiku 准确率偏低有一部分原因是它更愿意说"不知道"。换个角度读这组数字：Luna 答对的题比 Haiku 多，但它在不会的题上有 77% 会硬编一个答案；Haiku 答对的少，可一旦开口，可信度相对更高。做客服或摘要这类"宁可少说不能说错"的场景，后者更有用；做知识问答则前者占优。
  • AutomationBench-AA 35%：对比 Luna、Gemini 3.8 Flash 和 GLM-5.3 Flash 的 53–60%。一个发布前的安全 bug 导致模型过度拒答，Anthropic 在修，Artificial Analysis 会重跑并预计分数上升。
  • 规格：1M token 上下文（Haiku 4.5 是 200k），文本和图像输入、文本输出，5 分钟缓存写入每百万 $0.125（100K 以上 $0.625）。

其他基准声明（多为厂商或二手）

  • Anthropic 自报的跳跃：@ShayneRedford 汇总：OSWorld（电脑操作）15% → 72%；TerminalBench 0% → 39%，这与 Artificial Analysis 独立测的 Terminal-Bench 4.0 33% 不同；知识工作和推理提高 10–50%；大部分项目胜过 Luna；1M 上下文，最大输出约 12k token。Anthropic 的 @alexalbert__ 强调 Haiku 4.5 是 2025 年 10 月 15 日发的，所以这是不到一年的对比。
  • 文档解析（独立，ParseBench）：@LoganMarkewich 说总体接近 Luna，表格略好，图表理解略差。@jerryjliu0 算出每 1,000 页约 $1.2，按价格看表格和阅读顺序不错，图表、语义格式和边界框较弱。
  • 个人体验：@simonw 写了定价笔记并跑了他的"鹈鹕骑自行车"测试，说比贵 10 倍的 Haiku 4.5"好太多了"（对比）。

  • 看多：@kimmonismus："远好于 GPT-6-Luna，更接近 Sonnet 5.5……便宜又聪明。"@theo 喜欢分级定价，说 100K 以下只收五分之一的价"让人很清楚这模型是干什么的"，还惊讶于看到一个 Anthropic 模型出现在成本/智力图的最左边。@draecomino："Haiku 开到最高强度表现像前沿模型。"@kipperrii 认为小而便宜的模型现在更重要了，因为它们已经能做"一大堆有用的事"。
  • 竞争解读：发布被普遍读作针对 GPT-6 Luna，"rip gpt 6 luna"（@dejavucoder）。@kimmonismus 把 Sonnet 缓存降价看成 Anthropic 向 OpenAI 施压，对 API 额度的评论是"OpenAI：该你了"（帖子）。@teortaxesTex 说 Anthropic 现在有"所有实验室里最深的产品线"（Haiku/Sonnet/Opus/Fable 加 Mythos）对比 OpenAI 的 Luna/Sol/Astra，但他仍觉得 Anthropic"不太在意产品"，并把这读作它在 2026 年有多少余裕的信号。ThursdAI 的 @altryne 质疑中间档的意义："Sonnet 在 Opus 很贵的时候才有意义。"
  • 注意事项（主要来自数据而非批评者）：标价可能夸大了实际节省，因为最高强度下 token 用量约是 Luna 的 3 倍，抵消了一部分单价折扣；100K 以上的提示词贵 5 倍，对长上下文 agent 循环影响大；这两点大概解释了为什么 Cursor 说"短请求便宜 10 倍"而 Anthropic 说"平均便宜 75%"。事实回忆弱于 Gemini 3.8 Flash 和 Luna；过度拒答 bug 暂时压低了自动化分数；Arena 分数待出，独立的每任务成本要等分级定价支持。
  • 背景：Haiku 4.5 自 2025 年 10 月起是 Anthropic 的小模型，之后 OpenAI 的 GPT-6 Luna、Gemini 3.8 Flash、GLM-5.3 Flash 和 DeepSeek V4.1 Flash 都在低价端竞争。Haiku 5.5 的标价与 Luna 完全一致，多了推理强度控制和 1M 上下文，明确定位为多模型 agent harness 里的廉价工人：Claude Code 子 agent、Devin Fusion、Copilot 子 agent，以及压缩和摘要步骤。原文提到这轮动作正撞上关于 token 账单的更大争论（见 @theo）。

延伸知识

"每 token 便宜"和"每任务便宜"为什么不是一回事？ 模型报价都是按 token 算的，但你真正付的是完成一个任务的总账。推理型模型会在给出答案前"思考"很长一段，这些思考 token 也计费。Haiku 5.5 的单价和 Luna 一样，但做同一个任务它会多写两倍的思考过程，于是每任务的实际花费并不是 Luna 的一倍。这就是为什么 Artificial Analysis 要专门强调"成本数字是临时的"，也是为什么 Cursor 和 Anthropic 对"便宜多少"的口径对不上。看小模型的价格，一定要看每任务成本，而不是价目表。

为什么大厂都在推"大模型指挥、小模型干活"？ 一个 agent 跑一天的任务，大部分步骤其实是机械的：读一段日志做摘要、把过长的对话压缩、查一下数据库、判断一个结果是否通过。这些活用最强的模型做既慢又贵，但又必须做。于是架构上分成两层：Opus 或 Sonnet 这类大模型负责规划和难题，Haiku 这类小模型做批量的苦工。Anthropic 这次把 Haiku 定位成"子 agent"，Devin 叫它"副手"，Copilot 叫它子 agent，说的都是这个分工。分级定价里 100K 以下便宜 5 倍，也正好对应子 agent 通常处理的短任务。

推理强度（effort）和自适应思考是什么？ 推理型模型在回答前会先"想一段"，想得越久通常越准，但也越贵越慢。推理强度就是让用户自己选这个档位：low、high、xhigh、max 之类。自适应思考则是让模型按题目难度自己决定想多久，简单题不浪费，难题多花功夫。Haiku 5.5 是第一个带这两个开关的 Haiku，这也是为什么 Artificial Analysis 要分别报 high 和 max 下的分数和 token 用量：同一个模型在不同档位下，分数差几分，成本可能差近一倍。对使用者来说，这意味着"Haiku 5.5 多少钱"没有单一答案，得先定好用哪一档。
