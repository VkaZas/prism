来源：Latent Space《Meta Muse Wonder & Wonder Full: MSL’s Claude 5.5-tier Frontier Model》（原文），覆盖 10/10–10/12。本文只解读免费公开的部分：编者按和 AI Twitter Recap。

今日要点速览

Meta 超级智能实验室发布 Muse Wonder，14 个月后站到前沿。 Meta Superintelligence Labs（MSL）推出第二代模型家族 Muse Wonder 和 Muse Wonder Full，代号"西瓜"。Artificial Analysis 给 Wonder Full 56 分，距离榜首 Opus 5.5 的 58 分只差两分；Vals 把它排到第 5，领先所有 OpenAI 模型。编者的判断是：Meta 现在有了对应 OpenAI 的 Sol/Terra/Luna、Anthropic 的 Opus/Sonnet/Haiku 的完整梯队，但 Wonder 到底算不算 Fable/Astra 这一档，还不清楚。实践者的反应分成两派：Theo 把它评为与 Opus 5.5 同级的 S 级，@scaling01 认为 Meta 仍落后 3–6 个月。另外 Meta 的 Muse 应用留存曲线不好看，第 9 天左右就被 ChatGPT 反超。

头条：Muse Wonder 与 Wonder Full，MSL 的前沿模型

编者按说，Latent Space 一直在报道 MSL 用 14 个月成为前沿实验室的历程，今天最后一块拼图落下：Meta 的 Muse Wonder 补上了 Spark 和 Glimmer 之上的旗舰位置。有意思的是，Muse 没有公布具体尺寸，但 Wonder Full 在一些基准上胜过了 Fable 和 Astra；考虑到不同程度的后训练，Wonder 到底是不是 Fable/Astra 级别的模型，编者说"有点不清楚"。

发生了什么。MSL 发布了 Muse Wonder（内部代号"Watermelon"🍉），第三方评测把它放到接近前沿的位置，距离实验室成立大约 14 个月。

  • 发布前：几小时前内部人士开始发西瓜暗示：@rpnickson（"这是一个大西瓜……"）、@alexandr_wang、@finkd（"Muse 给我点了🍉"）。@kimmonismus 转发了泄露的定价：每百万 token 输入 $4、输出 $20，1M 上下文，最高推理强度的"Wonder Full"档仅限 MuseCode Power/Maximum Usage 计划。
  • 两个模型：@finkd 宣布了这个家族，并解释Muse Spark 是 MSL 的第一个家族，Wonder 是"规模大得多、先进得多的一类模型，把我们带到了前沿"。两个版本是 Muse Wonder（快速前沿版）和 Muse Wonder Full（完整版）。
  • 获取方式分开（@AIatMeta、Newsroom）：Wonder 通过 Meta Model API 和 Muse Code 提供；Full 只给 Muse Code 订阅者；Wonder 将驱动 Muse 个人 agent 产品，订阅者优先（@finkd）。
  • 定位：Meta 把它们宣传为"个人和专业 agent 工作"的最强模型。@alexandr_wang 列了三个头条特性：Active Memory（跨天、周、月的记忆）、Active Focus（突破障碍完成任务）、领域专长（金融和法律最强，"健康领域很强"）。
  • 训练故事：Wang 说自 4 月 Muse Spark 发布以来，Meta 同时扩大了预训练和 RL 的规模（帖子、研究博客）。@AIatMeta 的说法是"14 个月里从重建地基到推进前沿"。
  • 安全声明：@AIatMeta 说模型针对对抗性指令的鲁棒性和私人信息的谨慎处理做了训练，没有提到详细的 system card。
  • 发布日的额度 bug：Wonder 和 Wonder Full 消耗 Muse Code 额度异常地快（@alexandr_wang、跟进），当天修复并给所有用户重置了额度（修复）。Wang 承认"肯定还有问题在解决中"（帖子）。

独立评测（事实部分）。Artificial Analysis（@ArtificialAnlys）给出了最详细的第三方读数：

  • Intelligence Index v4.3：Wonder Full（max）56 分，Wonder（max）52 分，Muse Spark 1.3（max）是 48 分；Spark 1.3 到 Wonder 只隔了 6 周。Opus 5.5 以 58 分领先（@TheRundownAI）。
  • Wonder Full 在指数的全部十项评测上都有提升，agent 类涨得最多：Terminal-Bench 4.0 从 33% 到 57%，GDPval-AA v2.1 从 1681 到 1857 Elo，AA-Briefcase 从 1581 到 1729 Elo。
  • Wonder Full 在 10 项里的 6 项进入前三：GDP.pdf（33%）和 CritPt（33%）第一；GDPval 第二；AA-Briefcase、AutomationBench-AA（71%）和 SciCode（63%）第三。非 Full 版的 Wonder：Terminal-Bench 33% 到 52%，AutomationBench 58% 到 68%。
  • token 用量：两个模型每个指数任务输出约 54k，比 Spark 1.3 的 60k 少约 10%。对比：Gemini 4 Argon 62k，Fable 5.1 78k，GPT-6.1 Sol 38k，GPT-6 Astra 27k。输入方面 Full 用 6.44M，Wonder 用 7.69M。
  • 每任务成本：Wonder $4.52，主要是输入用量高。同表其他模型：Fable 5.1 $7.63，Opus 5.5 $5.98，Sonnet 5.5 $5.46，Astra $3.26，Argon $1.99，Sol $0.72，Spark 1.3 $1.60。Wonder Full 没有公开的 token 价格，算不出成本。
  • Coding Agents Index：Muse Code 里的 Wonder Full 68 分，与 Claude Code 加 Sonnet 5.5（68）并列，领先 Opus 5.5（66）；Wonder 63 分，Spark 1.3 是 54。
  • 规格：1M 上下文；输入文本、图像、视频和音频，输出仅文本；定价每百万 token 输入 $4、缓存输入 $0.20、输出 $20。

Vals AI（@ValsAI）：Wonder Full（Max）在 Vals Index 排第 5，比前代高 6.4 分，领先所有 OpenAI 模型。私有的 ProofBench 94/100，Spark 1.3 是 58，顶级模型 99–100（帖子）。Terminal-Bench 4 翻了一倍多，与 Fable 5.1 并列第四（帖子）。同分下 Terminal-Bench 少用约 30% 输出 token，ProofBench 少 40%，Vibe Code Bench 步数减半（帖子）。Wonder 排第 10，涨 7.9 分（帖子），每任务约 37 分钟（Full 是 57 分钟），Code Migration 62.6%（第 6），Terminal-Bench 4 涨 38.9 分且少用约 20% token。

Meta 自报的头条数字（经 @kimmonismus、@Yuchenj_UW、@TheRundownAI 转述）：SWE-Marathon 57.5%（Opus 5.5 46.3%，GPT-6 Astra 42.5%）；DeepSWE v1.1 79.0%（Opus 74.2%，Astra 74.1%）；Harvey LAB 13.1（Astra 8.6）；MemoryBench 85.5（Opus 81.5）。

其他第三方信号：@cline 确认 Wonder 领跑 DeepSWE；@iScienceLuvr 注意到 HealthBench Pro 与 Fable 5.1 持平；@AravSrinivas 说在 Perplexity 的 WANDR 评测上与 Fable 5.1 相比不落下风。合作方 @RayanKrishnan 的独立笔记：token 效率是最大的突破；网络安全基准上零拒答，且 Wonder 得分高于 Full；MSL 在对齐上"取得了实质进展"；模型是强执行者，但科学发现的直觉较弱。META 股价当天涨 3%。

Meta 强调的图表：非后训练任务与后训练任务的表现对比，用来证明没有刷榜、有"大模型味"。@giffmana 特别赞赏这张图；@scaling01 确认分布内对分布外的图是 Meta 出的。

X 上在聊什么

Meta 自己的说法（厂商观点）

  • 最详实的内部叙述来自 @shuchaobi：优化目标是"个人赋能"而非替代工作；在超长程指令跟随上下了大功夫；明确针对"偷懒"训练，让模型在放弃前足够坚持；定义和评分行为，并投入对齐以对抗高优化压力下的奖励作弊；声称模型能一次做出大多数 IMO 题，加脚手架能解一些开放研究问题。他另外描述了用它处理移民、买房和遗产规划（帖子）。
  • 评测先行：@alexandr_wang 说研究"从评测开始"，MSL 建了内部的 Personal Superintelligence Index（PSI）而不是追外部榜单，并声称"大模型味（我们量化了！）"。
  • "规模胜出"：@_jasonwei 说 Meta 大部分部门都转向支持这个模型，包括业务团队雇人类专家审数据，他还说它"多模态很棒"。@yashvarpatel 演示了用电脑操作 agent 做验证器：同一模型的生成 agent 配一个 CUA 验证子 agent 迭代，作为测试时扩展。
  • 放大器：Wang 转发了一串第三方夸奖，比如"在我的硬核物理测试里碾压了 Astra"（帖子）、"可能真的是世界上最好的 AI 模型"（帖子）。原文提醒把这些当作厂商放大。

实践者的反应

  • 看多的 Theo：有早期访问（@theo），把它排在与 Opus 5.5 同级的 S 级，高于 GPT-6.1 Sol，说 Meta 现在领先 Google"很多"，OpenAI 滑到第三（帖子、帖子）。他在 T3 Code Orchestrator V2 里让 Opus 调用 Wonder 做代码审查和架构审查（帖子），并澄清不是建议替换 Opus（帖子）。他夸它的文风独特，"不是又一个 Claude 垃圾蒸馏"，而且尊重 agents.md（帖子、帖子）。
  • @kimmonismus（早期访问，自称无报酬，帖子）：抵抗陷阱问题、精确跟随指令、自我检查代码，创意写作"有点干"；称现在是"三马竞赛"（帖子），并强调它比 $10/$50 的 Fable 5/5.1 便宜 60%（帖子）。
  • 其他使用者：@gneubig 说它在 OpenHands 的用户体验分析任务上表现好、比 GPT 模型简洁。@QuixiAI 认为 Wonder Full（high）优于 Astra 但低于 Claude Code 的 Fable/Opus 5.5，快得多，能处理 Codex "卡住"的编译器工作。@clairevo：agent 任务、编程和邮件强，前端设计、SVG、视频和创意弱。
  • 怀疑或中立的 @scaling01：估计 Meta 仍落后 OpenAI 和 Anthropic 约 3–6 个月（帖子）。他的 SVG 对比（披露是 Meta 提供的访问）称 Wonder Full "太花哨"，过度堆物体数量，是"约 4 个月前的优秀结果"（帖子）。好的一面是准确率对成本、准确率对输出 token 的曲线不错（帖子）。他认为它"很可能不是循环模型"（帖子），想要详细得多的 system card（帖子），并反驳"OpenAI 完了"的说法，理由是 OpenAI 的内部数学结果（帖子）。
  • @teortaxesTex 在等第三方确认"Fable 级别"（帖子），并认为 OpenAI 和 Anthropic 领先得足够多，可以在彼此之间"控速"，因为公开版本落后于内部模型（帖子）。
  • 访问抱怨：@theo 反对 Full 仅限订阅且没有定价。他说两个版本是"非常不同的模型"（帖子）：Full 在 AA 上用更少 token 追平 Opus xhigh，Wonder 在与 Full 相同的 token 用量下低于 GPT-6.1 Sol（帖子）。
  • 3D 演示之争：早期的否定基于较弱的 three.js/3D 演示。@theo 认为"3D 刷分"本身就是一种刷榜：实验室最近都加了 3D 的 RL 环境，Opus 5.5 在 3D 上比 Fable 5.1 强约 4 倍，尽管"最多是好 5% 的模型"。@alexandr_wang 承认："我们没有专门训练 3D 演示游戏……回头看也许应该。"@teortaxesTex 反驳说强实验室的优势正是有一批对这类演示有眼光的员工，three.js 输出仍然有说明性。同一天 Artificial Analysis 推出了 AA-3D，一个 three.js 场景基准，Claude 和 Astra 模型领先。

背景：Muse 产品与战略

  • 留存（Sensor Tower，经 @kimmonismus）：Muse 第 1 天 73.3%，第 7 天高于 30%，第 14 天 22.5%；ChatGPT 第 14 天 26.8%。ChatGPT 在第 9 天左右反超 Muse。@scottastevenson 认为 Muse 的曲线在向零倾斜而不是走平，猜测是对主动推送通知的疲劳，@zachtratar 收到一条多余的 Uber 通知印证了这点。
  • 看多与治理：@garrytan 赌"Muse 会赢"。@berman66（Runlayer）推出了面向企业的 Muse 治理工具，并提到有公司在 Muse "失控"、泄露数据和发送未授权邮件后将其封禁。
  • 政策含义：@AndrewCurran_ 认为前沿的"控速"已经被打破：一家美国实验室叛逃就逼其他家加速，扎克伯格有算力也有特朗普的耳朵，2029 年前不会有变化。
  • 定价：@scaling01 觉得定价偏贵（"那它最好能打败 Opus 5.5"）。AA 的成本核算把 Wonder 放在 Anthropic 与 OpenAI/Google 之间。

Agent、RL 与自我改进研究

  • Sakana MASS：一个 27B 模型把自己的副本组织成多 agent 工作流，然后用最佳团队的轨迹微调。两轮后研究类基准上每输出 token 的得分涨 1.2–1.6 倍；多 agent 轨迹比单 agent 训得更好，作者提醒模型与自己的评判者共享盲点的安全风险（@SakanaAILabs）。
  • QwenGyre：面向超长程 agent 的弹性 RL，比共置训练快最多 1.85 倍。在 Qwen3.8-2.4T-A95B 上、每次 rollout 约 70 万 token，NL2RepoBench 在 48 步内从 52.5% 到 58.5%，训练时间少约 44%（@Alibaba_Qwen）。
  • GitSwarm（Meta）：数百个异步 agent 共享一个 Git 仓库，没有中央规划器，解出了 IMOProofBench-Advanced 全部 30 题，ProgramBench 79.4%，单 agent 是 65.1%（@omarsar0）。
  • 其他：Fork-and-Flush 周期性地分叉 autoresearch agent 并清空上下文，帮它们逃出"想法盆地"，同算力下在 13 个长程任务中的 12 个胜过单次运行和 best-of-N（@DimitrisPapail）。nanoswe 是一个从零训练、花约 $1,000 算力的 1.7B 编程 agent，SWE-bench Verified 25.5%（@rdolmedo_）。前沿 agent 写的测试抓到的逻辑突变不到 55%（@nielstron）。

推理系统、芯片与电力

  • Microsoft Maia 300：微软声称每兆瓦 token 比领先 GPU 系统多 40%，机架级吞吐是 Maia 200 的 7 倍（@Microsoft），计划从 2027 年起成为微软自家产品的主要推理系统（细节）。
  • 其他硬件：Intel Crescent Island 有 480 GB LPDDR5X、1.5 TB/s 带宽、350 W 下 1.3 PF 的 FP8（@aschilling）。ReplaySSM 缓存 SSM 的输入而不是状态，解码最多快 1.47 倍、投机解码快 2.1 倍，已在 GLM-5.3-Flash 和 Kimi-K3 的生产环境运行（@zwljohnny、@tri_dao）。
  • 电网约束：密西西比的 Entergy 警告将在高峰时段限制 Amazon 数据中心的用电，AWS 以 Project Falcon 回应，让电力公司自己把站点切到备用电源（报道）。
  • agent 基础设施：Perplexity 把每个项目当作一个 Git forge 运行，临时 agent 沙箱提交到 S3，不到 2% 的提交冲突，在金融文档问题上 grep 以 63% 对 37% 胜过语义搜索（@AravSrinivas）。

专用模型与开发者产品

  • GLM-Legal（Z.ai）：基于 GLM-5.3-Flash，是 Harvey 的 LAB 和 LegalBench 上第一的开源权重模型（@Zai_org、@ValsAI），但在 LegalResearchBench 上差 4 分，检索判例的频率低得多（细节）。
  • 定制模型的经济学：Coinbase 用 Qwen3.5-9B 微调做欺诈防范，以更低成本和延迟胜过前沿模型（@brian_armstrong）。River AI 推出比第一方 DeepSeek V4.1 Flash 和 GLM-5.3 Flash 便宜 20% 的推理服务（@ibab）。
  • 决策模型继续：Decision 3.0 是 0.6B 到 27B 的开源模型，在 Jev Decision Index 两个榜上都排第一（@XunzhuoLiu）。SubQ Snap 有 384K 上下文、每百万输入 $0.05、输出免费（汇总）。
  • 产品更新：Codex 和 ChatGPT 里 GPT-6.1 Sol 的默认上下文从 272K 涨到 500K（@reach_vb）。OpenCode 2.0 发布（@opencode）。

延伸知识

什么是"大模型味"（big model smell）和"刷榜"（benchmaxxing）？ 刷榜指针对公开基准做专门训练，分数好看但换个任务就露馅。Meta 这次特意放了一张图：模型在"后训练时练过的任务类型"和"没练过的任务类型"上的表现对比。如果两边都强，说明能力是泛化的，不是背题，这种泛化出来的、说不清来源的通用能力，圈内俗称"大模型味"。Theo 对 3D 演示的辩护用的是同一套逻辑的反面：Opus 5.5 在 three.js 上比 Fable 5.1 强 4 倍，但整体只好 5%，说明 3D 分数高很可能是专门练过，看 3D 演示判断模型强弱本身就不靠谱。

Wonder 和 Wonder Full 为什么被说成"非常不同的模型"？ 同一个模型家族发两个版本，通常意味着不同的推理强度或不同的后训练深度。Theo 的观察是：Full 用更少的 token 就追平了 Opus 的最高强度，而 Wonder 在同样 token 用量下还不如 GPT-6.1 Sol。也就是说差距不在"想多久"而在"底子"。这解释了编者按里那句"不太清楚 Wonder 是不是 Fable/Astra 级"：Full 可能是，Wonder 可能不是，而外界能通过 API 用的只有 Wonder。做采购决策的人要看清自己买的是哪一个。
