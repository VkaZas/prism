今日要点速览

Claude Code 两位核心同日离开 Anthropic。 @trq212（Thariq）自己发了离职声明，据 @buildwithrajath 和 @YxzRainy 转述，做 Claude Code 桌面应用的 Anthony Morris 同一天也走了；The Information 同期说 Anthropic 准备下月上市，圈里于是一边猜原因，一边拿 GTA VI 11 月 19 日发售开玩笑，而「被 SpaceXAI 挖走」目前只是单一来源的传闻。第二条线在 OpenAI：Codex 的「28 天」活动据说进入最后一周，Microsoft 和 GitHub 的配置里都出现了 GPT-6.1 Terra，Codex 负责人 Tibo 一边公开招人要把 dots 做到 10 亿用户，一边和 Meta 的 Alexandr Wang 在个人 agent 上互相嘲讽，Grok Bot、Muse、dots 三家的个人助手之争也把中文圈带热。第三条线是算力：Musk 回帖预言会出现大量烂尾数据中心里的「搁浅算力」，The Information 则说 Nvidia 正用 1700 亿美元以上的投资和承诺托着自己的需求、CoreWeave 成了融资风向标，a16z 的数据却显示 GPU 租价仍远高于折旧表，投资圈因此分成看空 neocloud 和看多 $SPCX 两派。第四条线是安全：AI 网络攻击能力成了这周最大的争议话题，The Information 还报道 Altman 对员工说行业需要更好的办法放慢危险 AI 的发展。中文圈另有两个没有任何人证实的传闻：Kimi K3.1 的宣发话术被曝光，以及字节内部抢算力的「宫斗」段子。
