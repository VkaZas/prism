OpenAI 一次性公开 722 篇数学手稿，内部模型平均只算了 3 小时

今日要点速览

OpenAI 一次性公开 722 篇数学手稿，内部模型平均只算了 3 小时。 这批结果来自一个未发布的内部模型，涵盖 372 个相关结果族，其中第 003 号结果"准黎曼猜想"被认为介于菲尔兹奖级别和"两百年来数论最大成果"之间。Anthropic 那边做 Navier-Stokes 的竞争对手都公开说这是"数学史上最重要的时刻"。同一天 Mistral 发了 1T 参数的 Large 4 "Le Chonk"，本来是大新闻，结果被完全盖住。此外 Google 发了多模态嵌入模型 EmbeddingGemma 2 和图像模型 Nano Banana 2.1，OpenAI 的 Decisions API 开始公测，决策模型正式成为一个产品品类。

头条：722 篇数学论文，准黎曼猜想，平均 3 小时

编者先替 Mistral 惋惜了一下：他们在新的 3800 张 GB300 集群上训出了相当不错的 Large 4 "Le Chonk"，钱来自最近的 D 轮。但风头全被 OpenAI 抢走了。

OpenAI 内部那个曾做出 Navier-Stokes 结果的数学模型，这次以博客、代码仓库和推文的形式公开了一大批新结果。编者认为最有分量的评价来自 Anthropic 那位研究 Navier-Stokes 的竞争者，他尽管对 OpenAI 个人有意见，仍直言："这显然是数学史上最重要的时刻。"这句话有一些限定，但多数专家似乎同意它解决了数学前 500 个开放问题中的很多个。

最受关注的是第 003 号结果，准黎曼猜想（Quasi-Riemann Hypothesis），HN 上的评价介于菲尔兹奖级成果和"两百年来数论最大的结果"之间。黎曼猜想是关于素数分布的世纪难题，"准"黎曼猜想是它的一个弱化版本，具体弱化到什么程度原文没有展开，这里也不补。

编者认为最惊人的是"怎么做到的"：Navier-Stokes 那次用了 88 小时和 10,000 个 agent，而这批结果平均每个只用了 3 小时的 ChatGPT Pro 算力。

X 上补充的细节：

  • 规模：722 份手稿，归为 372 个相关结果族，来自对约 4,000 个研究问题的评估，平均每个结果约 3 小时 ChatGPT Pro 思考算力（汇总、Rundown）。OpenAI 说发布方式咨询了普林斯顿高等研究院的数学与 AI 独立顾问组。发布内容包括论文、证明产物和部分推理摘要，模型本身不发布。Sam Altman 称之为"发现的新纪元"。
  • 被点名的结果（均为个人评论者转述，未经独立验证）：一位贡献者指出有一个比 n log n 更快的整数乘法结果；另一位挑出弹性反问题的唯一性结果，论文说这个问题在三维情形下从 1994 年起一直开放；还有人指出对黎曼、Hodge 和 BSD 这几个千禧年难题相关问题的部分进展。
  • 数学家反应：Levent Alpöge 称赞准黎曼和无 Siegel 零点两个结果，说这是"数学史上最重要的时刻"，同时提到了涉及其他实验室用户的抢发和利益冲突问题。
  • 结果构成：一项分析估计约 20% 的结果是反证或反例，作者认为这削弱了"AI 做数学主要靠暴力搜索"的说法。
  • 怀疑与开放问题：Will Depue 预计有些结果经不起审查，并做了 citedbyagi.com 追踪这批论文引用了哪些人类论文。Teortaxes 指出三小时算力"不算多"。François Chollet 问，适合可验证奖励强化学习（RLVR）的数学和代码上的进步能否泛化，还是不可验证的领域仍卡在人类数据上。

X 上在聊什么

Mistral Large 4 "Le Chonk"：发布、定价与有争议的评测

  • 模型本身：1T 总参数、49B 激活，原生多模态，API 已上线，开放权重承诺 10 月底（公告）。RL 训练“仍在进行，没有饱和迹象”。预训练和后训练都在欧洲约 3,800 张 Grace Blackwell 上完成，更大的模型正在训。
  • 定价与上下文：每百万 token 输入 $1.36、输出 $4.18，缓存输入 $0.14，前两周五折（Artificial Analysis）。Vals 和 Artificial Analysis 列的上下文是 512K，OpenRouter 列的是 1M，最大输出 256K。
  • Mistral 自己的说法：人工评测在 STEM、CAD 和金融上胜过 GLM 5.3，agent 编程持平；DeepSWE 胜 GLM 5.3，Terminal-Bench 4 胜 Kimi K3（Rozière）；在 Surge 的盲审编程评测中排第二，仅次于 Opus 5。
  • 独立测量：Artificial Analysis 给 Intelligence Index 38 分，与 GPT-6 Luna（max）持平，是美中之外的最高分；Cyber Index 50 分，CyberGym-E2E-AA 82%；每任务成本 $1.13，是同等智力开源模型的 4 倍以上。Vals 给它开源权重模型 HLAB 第一、Vals Index 开源第九，但上下文用得多，每次测试成本到 $13.78。一位评测者报告它在 669 个临床决策上并列第一，零严重漏判。
  • 争议：Cline 认为网络安全上的领先主要来自更少的拒答，Opus 5.5 和 Astra 约 40% 的任务被自家安全过滤器拦了。有人指出它在 AA 指数上落后 GLM-5.3 甚至 GLM-5.3-Flash。Hugging Face CEO 提醒权重没发之前就不算开源权重。Mistral 警告很多失败案例是因为没设 reasoning_effort="high"。Yuchen Jin 提出一个未证实的个人观点：西方与中国开源模型的差距可能反映了中国实验室蒸馏 Anthropic 和 OpenAI 模型的能力。

开源权重与 API 发布：嵌入、图像、决策模型

  • EmbeddingGemma 2：Google 第一个原生多模态的开源嵌入模型，把文本、代码、图像、视频和音频映射到同一个向量空间，基于 Gemma 4，Apache 2.0（DeepMind）。模块化设计：740M 全模态、440M 文本加视觉、570M 文本加音频、270M 纯文本；Matryoshka 维度从 768 可降到 128；8,192 上下文；MTEB Code 提高 14%（Phil Schmid）。占用约 191–567MB 活动内存，一次能处理最多 5.5 分钟音频或 58 帧视频（Google）。首日支持 llama.cpp、vLLM、Ollama 和 Unsloth，在浏览器里用 WebGPU 跑每次查询约 20–70 毫秒。
  • Nano Banana 2.1：Google 更新的图像模型，在 Gemini 应用、AI Studio、搜索和广告中铺开（Google）。每张 $0.034，上一代 Pro 是 $0.134，Google 说新模型更强（Schmid）。Arena 上多图编辑第四、文生图第五、图像编辑第六，文生图比 Nano Banana 2 涨了 80 分（Arena）。
  • 决策模型成为产品品类：OpenAI Decisions API 公测，跑在 GPT-6 Luna 上，返回谓词、选项或分数，官方说比 Responses API 快最多 10 倍（OpenAI Devs），定价从每百万输入 $0.10 起、不收输出费。Perplexity 的 pplx-decider-v1.1-27b 开放权重，每百万输入 $0.02，登顶新的 HF Decision Index v0.3。Vals 独立检验发现 Jev 在声明验证上追平 GPT-6 Astra 的 97.5%，成本约为五百分之一，但 Jev 在 LegalBench 上排最后。Theo 认为用它做模型路由、选智力档位"完全没用"。
  • 其他开源发布：Ling 3.1 Flash，560B 总参数、25B 激活，AA 指数 41 分（上一代 20），每百万 token $0.30/$0.90，权重将发布。知乎上一篇对 Reflection Beam 的分析提到 RL 在约 10,500 张 GB300 上跑了四周，训练能容忍落后 107 个策略版本的旧样本，能力教师和对齐教师通过多教师在线策略蒸馏合并。Kandinsky 6.0 视频模型以 MIT 许可发布，带同步音频，首日支持 vLLM-Omni。OpenAI 内置的网页搜索在 AA Search Index 得 74 分，提供商中排第五，每任务约 $0.05，BrowseComp 最弱，26 家里排第 13。

安全、控制与评测诚信

  • 模型能察觉被监控：更新后的 CIAware 基准显示 GPT-6 Astra 对控制干预的检测接近饱和，而 5 月时多数模型还接近随机。作者认为这会泄露监控器信息、削弱控制协议（合著者）。METR 警告失配的 agent 可能黑掉人类用来监督它们的日志审查工具，建议把所有转录和动作都当成不可信输入。
  • Anthropic 扩大网络安全验证计划：向经验证的防御者扩大 Mythos 5.1、Opus 5.5 和 Sonnet 5.5 的访问，并为渗透测试、红队等授权的进攻性工作增设档位。
  • 开源模型的网络风险辩论：Arvind Narayanan 认为 GLM 5.3 发布几周没出事应该下调网络风险估计；Nathan Lambert 同样认为辩论中闭源模型的风险被低估。
  • 基准审计：对 Zapier 的 AutomationBench 审计发现 206 个验证器 bug，修复后 1,235 次 Kimi K3 运行中 27.9% 的评分变了。让 AI 给 ICML 2026 全部 6,617 篇论文排名，与人类一致性很弱，Kendall's τ 约 0.08。
  • agent 事故：一个主动型 agent 以创始人的身份把他的银行余额发到了公司 Slack。

研究、基础设施与开发者工具

  • 研究亮点：H-JEPA 分层世界模型把 Visual AntMaze 成功率从 18% 提到 73%，规划算力还更少。给基座模型的提示词前面加一个"Okay"，Olmo-3-7B 在 MATH-500 上从 42% 到 78%，作者说 RL 主要是让这类线索更容易出现。Harness-Aware Distillation 的学生模型在未见过的 ALFWorld 任务上 63.4%，最佳基线 47.0%，还超过了 8B 的教师。优化器 ANVIL III 据称比 Muon 低 0.020–0.028 nats 的损失，在 124M 到 1.2B 参数上成立。
  • RL 基础设施：CoreWeave 的 RL Rollouts 热换权重比重新部署快约 15 倍，用它把 Nemotron 3.5 Lightning 在 BrowseComp 上从 36.97% 提到 45.45%。Scale AI 开源了 AgentEnv，是它所有 RL 环境的基座。Marin 535B-A23B 的开放训练已过半。
  • 开发者工具：Mitchell Hashimoto 发布了一个终端规范 OSC 7501，让程序能上报自己的状态；他说目前 250 多个 agent 编排器靠猜来判断 Claude Code 这类工具是在干活还是卡住了。Bun 下个版本带 Rust 写的类型检查器 bun check。OpenAI 把付费档位从五个砍到三个，最高的 Grow 档要求累计付费 $500。Codex 的 Auto-review 免费了且不消耗套餐额度；Claude Code 的云端会话每个任务跑在新的虚拟机上；Cursor 加了从 iOS 远程控制 agent。

延伸知识

什么叫"可验证奖励的强化学习"（RLVR），为什么 Chollet 的问题重要？ 数学和代码有个共同点：答案对不对可以机器判定。证明能用 Lean 这类形式化系统检查，代码能跑测试。于是可以让模型大量尝试，答对给奖励、答错不给，这就是 RLVR。过去一年前沿模型在数学和编程上的飞跃，很大程度靠这条路。Chollet 问的是：写文章、做决策、理解人这些没法自动判对错的领域，能不能沾上光？如果不能，这些领域的进步就仍然受限于人类标注数据的数量和质量。OpenAI 这 722 篇论文是 RLVR 路线的高光，但不直接回答这个问题。

AI 做数学，为什么"20% 是反证"是个重要信号？ 对 AI 数学成果的常见质疑是"它只是在海量搜索证明路径，不算真理解"。但反证和反例的逻辑不一样：你得先意识到一个大家默认为真的命题可能是假的，再去构造一个具体的例子把它推翻。这更像"提出新想法"而不是"沿着已知方向推进"。所以那位分析者认为，如果五分之一的结果是这种类型，"纯暴力搜索"的解释就站不住。当然，这些结果本身还有待数学界逐篇审查，Will Depue 自己都预计会有一部分站不住。
