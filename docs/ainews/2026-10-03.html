今日要点速览

编者说今天没大事，但性价比榜单正在重排。 编者按只有一句话："如果你还在看这封信，不如去过周末。"不过 X 上的信息量并不少：GPT-6.1 Sol 以 Astra 五分之一的价格进入 Agent Arena 前五，Sonnet 5.5 首发就排第三，Anthropic 包揽 Agent Arena 前三。"决策模型"（decision model）这个新品类开始成型，llama.cpp 都加了专用接口。研究端的亮点是 Hugging Face 证明同一套模型权重换个 harness 分数能从 62% 掉到 33%。产业端最热的帖子是纽约时报关于 Anthropic 的 Chris Olah 和教皇 AI 通谕的报道。

头条：GPT-6.1 Sol 和 Sonnet 5.5 重排性价比曲线

编者按本身没有头条，所以这里把 X 上讨论最多的一组拿出来说。

OpenAI 给 GPT-6.1 Sol 定价每百万 token 输入 $2、输出 $10，而 Astra 是 $10/$50（定价汇总）。官方声称它在 DeepSWE v1.1 上比 GPT-6 Sol 高 6.4 分，在 AutomationBench 上比 Opus 5.5 高 2.2 分（汇总）。OpenAI 员工的说法是"好、便宜、还快"（@reach_vb）。

第三方的 Agent Arena 给出了更可比的数字：Sol [Max] 以第五名入榜（+11.23%），每个任务的中位成本 $0.56（@arena）。换算一下：它比 GPT-6 Sol 便宜 39%，分数还高 1.52；比 Astra 便宜 81%，分数只差 1.04。

Anthropic 这边，Sonnet 5.5 [Max] 首发排第三（+12.5%），在 Chat 类别排第一，但每任务 $2.74，比第二名 Opus 5.5 的 $1.58 还贵，所以没落在 Pareto 前沿上（首发、前沿）。Pareto 前沿的意思是"同样价格下没有更好的、同样分数下没有更便宜的"那条线。尽管如此，Anthropic 的模型现在占了 Agent Arena 前三。

为什么重要：过去一年的竞争逻辑是"谁更强"，现在转向"每个任务花多少钱能做到什么分数"。Sol 的定位就是用 Astra 五分之一的价格做到接近 Astra 的事，这会直接影响开发者选哪个模型跑 agent。

X 上在聊什么

GPT-6.1 Sol 与 Sonnet 5.5 之外的榜单动态

  • WebDev 榜短暂易位：Sol 一度冲到 Code Arena WebDev 第三，随后被 Sonnet 5.5 挤到第四（周报）。Sonnet 在 WebDev 上只比 GPT-6 Astra [Max] 低 2 分，成本却低 80%。Gemini 4 Argon [High] 拿下 Text Arena 第一。开源阵营里 MiMo-V2.6-Pro 和 Flash 进入 Agent Arena，在开源模型中排第五和第九。
  • 推理风格差异：Design Arena 读了 324 份思考摘要，发现 Astra 的犹豫模棱两可的频率是 Opus 5.5 的约 20 倍，而 Opus 大约五次里有四次早早下结论（@DesignArena）。
  • StepFun 的 Step 5 Preview：在 Vals 榜上开源权重模型里排第七，每任务 $2.54，平均一个任务要跑近两小时，上下文 1M token（Vals、细节）。
  • 传言（未证实）：有人说 Claude Fable 5.5 下周发，而且胜过一个因安全问题延期的"Astra 6.1"，发帖人自己承认两条都无法核实（@kimmonismus、后续）。另外有人发现一个"GPT-6 Astra Lite"的条目，@scaling01 猜它就是 Sol（@scaling01）。
  • 决策模型走进本地推理：llama.cpp 加了 /v1/systemone 端点，用于本地跑"Jev 风格"的决策模型（@ggerganov）。Perplexity 称其 pplx-decider-v1-27b 在 11 个基准上平均 85.7%，超过 Jev（@AravSrinivas）。也有人泼冷水：@mervenoyann 说决策模型就是零样本分类器换了个名字（推文）。

Agent harness、助手与开发者工具

  • Sam Altman 最爱的 OpenAI 产品是 dot：他说 dot 每天都在学他的工作流、越用越好（@sama）。Dot 能跨应用保留上下文、协调 Codex 任务、标出需要关注的事项（@OpenAIDevs）。有人更喜欢 Grokbot 的多 agent"幕僚长"方案（@kimmonismus），也有人用 Pi 加一个 Telegram 网关自己拼了个山寨版（@_alejandroao）。
  • Meta 的 Muse 做硬件生态：Meta 开源了 ESP32 固件和 Linux SDK，让人做能接 Muse 的硬件（@natfriedman）。还自己做了 5,000 台智能家居网桥 Muse Home Link，订阅用户免费领，领完为止（@alexandr_wang、发货）。
  • harness 越来越可塑：DeepSeek Harness 出了 macOS 和 Windows 桌面版，Linux 用 npm 装 @deepseek-ai/dsh（@deepseek_ai）。Claude Code 的 mods 是带中间件式 hook 的插件（@lydiahallie），新插件 "You should know" 会开一个旁路 agent 专门提醒你可能漏看的重要输出（@ClaudeDevs）。Pi Durable 借 agents SDK v0.26.0 跑在 Cloudflare Durable Objects 上（@mattzcarey、@badlogicgames）。@omarsar0 把这一串发布总结为向"可塑 harness"转向（帖子）。
  • T3 Code 重写合并：项目用户过 40 万（@theo），一个耗时 4 个月、823 次提交、改了 1,912 个文件的 PR 合并了（@maria_rcks），新增 Pi 支持、跨厂商 delegate_task、ACP 注册表、线程分叉、中途换模型、子 agent 谱系视图和定时任务（功能列表）。
  • 平台更新：OpenAI Agents API 加了一次调用的浏览器电脑操作、Bedrock Managed Agents 和可移植环境，声称 99.97% 的回合可靠性和快 20% 的工具调用（@stevendcoffey）。Cursor Rollouts 抓到回归时会找出肇事 PR、开 issue、给一键云端修复（@cursor_ai）。

研究：agent 训练、长程控制与 AI 做数学

  • 同一权重，换 harness 分数差一倍：Hugging Face 发现同一套模型权重在一个 harness 里得 62%，换一个只有 33%（@huggingface）。他们做了一个代理，能讲 OpenAI、Anthropic、Gemini 三家的 API 格式，记录采样的 token ID 和对数概率用于训练，harness 本身不用改。结果 LFM2.5-2.6B 在四个 harness 上从 42% 提到 54%，工具调用少了 31%；对比之下用 3,189 条 Qwen3.8-27B 轨迹做 SFT 停在 47.5%。训练器、数据和七个模型全部开放。
  • 强化学习效率的几条新路：ProVer 让评判模型定位轨迹中的决定性片段，再用两侧的 rollout 给它分配优势值，相对 GRPO 提升 +9.91%（Qwen3.5-2B）和 +7.12%（Qwen3.5-4B）（@omarsar0）。Frontier Learning 专挑"模型有时能解有时不能"的题，因为永远能解或永远不能解的题给 GRPO 的梯度是零（@robinfaro13）。另一篇论文说 SFT 泛化差是因为数据是离线的而不是目标函数的问题，把专家轨迹改写成基座模型自己的风格就能补上差距（@maximelabonne）。
  • 长上下文仍是硬伤：NVIDIA 的 Long-Transduction 研究测得七个开源模型从 4K 到 128K 上下文平均掉 62.8% 的准确率（@dair_ai）。微软的免训练方法 FOCUS 把峰值上下文砍掉最多 48%，任务成功率反而最多提高 8.9 分（@dair_ai）。Meta Superintelligence Labs 报告，加一个专门的控制器能把 GPT-5.5 在 ProgramBench 上从 63.7% 提到 71.5%，用同样的工作模型和预算，而 Codex 是 58.0%（@dair_ai）。
  • 多 agent 协作并不乐观：AgentWorld 里不到三分之一的多 agent 动作对完成任务有帮助，协调类任务成功率只有 12%（@omarsar0）。
  • AI 做开放数学问题：Meta 用 Muse Spark 1.1 和 1.2 在普通 meta.ai 聊天界面、不加任何脚手架，产出六篇关于开放问题的论文（@AIatMeta、清单），每篇都标注哪些段落主要由人写、哪些由 AI 写，并有第二组数学家复核。Google 的 Cogentic 是一个 Gemini 多 agent 系统，在五个开放理论问题上得到新结果（@omarsar0），每份草稿要过两个对抗式验证器，agent 之间共享一份已验证引理的账本，多数问题约 100 次调用，最难的约 1,000 次。

基准、评测诚信与安全

  • 搜索工具到底值多少：Vals 的 Web Search Index 固定模型和 harness，只换搜索工具，在金融和法律任务上打分（@ValsAI）。不带搜索时 agent 在法律任务得 2.9%、金融 7.4%，带上搜索是 30–50%。Vals 还引了一项研究：某模型不用搜索答对了 44.5% 的 BrowseComp（细节）。
  • 新基准的争议：一个 SWE 找 bug 基准让 agent 从旧提交出发、对照后来修掉的真实 bug 打分。Lucas Beyer 批评它主要测记忆，而且构造方式容易被针对训练（@giffmana）；作者回应说只要排除测试集，针对找 bug 训练没问题（@OfirPress）。David Rein 则质疑 Terminal Bench 背后的 Harbor 框架是否允许 agent 在评测前修改自己的轨迹，并说自己可能读错了代码（@idavidrein）。
  • 开源模型的攻击能力：The Batch 报道 GLM-5.3 在利用漏洞上几乎追平 Claude Mythos，12% 对 14%（@DeepLearningAI）。有评论者说 GLM-5.3 Flash 在 ExploitBench 上超过了 Mythos Preview（@teortaxesTex）。一个去审查版的 GLM-5.3 已在 Hugging Face 流传（@kimmonismus）。
  • Karpathy 的"陆地还是海洋"：对 16,200 个经纬度坐标逐个问模型"这是陆地还是水"，把答案画出来就是一张能认出来的世界地图（@karpathy）。这是模型内部有世界知识的直观证据。

推理、硬件与系统

  • 从 DeepSeek 开源内核反推昇腾 950：一篇分析从 DeepGEMM、FlashMLA、TileKernels 和 DeepEP 推断芯片布局（@ZhihuFrontier）：32 个 AI 核，每核一个 Cube 核配两个 Vector 核，估算峰值约 432/865/1,730 TFLOPS（BF16/FP8/FP4）。有人指出虽说 8 月就开售，供应可能有限（@teortaxesTex）。
  • 低精度格式之争：Prime Intellect 把 MLA 的潜变量存成 NVFP4，每行从 576 字节缩到 352 字节，缓存的 token 比 FP8 多约 50%（@PrimeIntellect）。Stas Bekman 在 B200 上测得 NVFP4 比 MXFP4 效率高约 9%、精度也更高（@StasBekman）。
  • 内存与互联：NVHBM 把内存控制器挪到定制基底芯片里，声称比 HBM4E 带宽高最多 30%、功耗低 15%（@vikramskr）。Micron 说 NVHBM 会改善其利润率，@vikramskr 不同意（反驳）。
  • 算力经济学：Epoch 估算 AI 基础设施很快能支撑数亿到数十亿个 agent（@EpochAIResearch），但仅 20% 的利用率就意味着每年 $2.6–5.3 万亿的支出，而到 2027 年底实验室收入大约只有 $1 万亿（细节）。Altman 称 Cerebras 是速度方面的紧密合作伙伴（@sama）。

延伸知识

Pareto 前沿是什么意思？ 把每个模型画在一张图上，横轴是每任务成本，纵轴是分数。如果一个模型"比它便宜的都没它强，比它强的都没它便宜"，它就在 Pareto 前沿上，是值得考虑的选项；否则总存在一个既便宜又强的替代品。Sonnet 5.5 排第三却不在前沿上，原因就是第二名 Opus 5.5 既比它强又比它便宜。看榜单时只看名次容易被误导，看前沿才知道该买哪个。

决策模型（decision model）为什么突然火了？ 普通大模型的输出是一段自由文本，agent 要从里面解析出"选 A 还是选 B"。决策模型反过来：给它一组选项，它一次前向计算直接返回每个选项的概率，不生成文字。好处是快、便宜、输出格式稳定，适合做路由（该用哪个模型）、分类（这条请求危险不危险）、判题（答案对不对）。TypeSafe 的 Jev 是这个品类的参照物，Perplexity、Cloudflare、Clef 等都在跟进。质疑者说这不过是零样本分类器换了名字，这个争论后面几期还会继续。
