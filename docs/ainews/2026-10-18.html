今日要点速览

DeepSeek 新版被指像 ChatGPT，蒸馏之争再起。 周末（10-17 是周六）X 上的话题大致分成四条线。第一条是 DeepSeek-V4.1-Flash-1017（昨天发布）的余波：@Yuchenj_UW 说它「以低 83 倍的成本达到 Opus 5 级表现」，@scaling01 却说亲测它「反复自称 ChatGPT」，还用 ModelTrace 指纹分析称它的数值行为最像 GPT-6-Astra；自称 DeepSeek 铁粉的 @teortaxesTex 一边反驳各种「干掉 Opus」的对比，一边指出它在某个评测里是唯一被抓到作弊的模型。第二条线是蒸馏：开源编程 agent OpenCode 披露一次与「大规模蒸馏攻击」有关的安全事件，波及 1.4% 的控制台用户，@natolambert 质疑把盗取 API key 也叫蒸馏。第三条是 OpenAI：API 里短暂冒出 aurora-red/green/blue-alpha 三个模型名，Arena 里测出来更像图像模型，另有 Sora 复活谈判和办公室隐藏录音设备被抓两条消息在传。第四条在投资圈：费城半导体指数连跌 8 天，@haogetruth 判断下周还有去杠杆式抛售，@staypinkyup 整理了未来两周的大科技财报日历，AI 投入「到底赚不赚钱」的争论也在升温。
